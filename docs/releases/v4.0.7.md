# v4.0.7 — Raw Shred instructions and Pump execution fixes

Released 2026-10-19.

Unknown third-party Shred instructions emit RawInstruction rather than inferred Pump trades. Payloads preserve the program ID, instruction index, ordered accounts including duplicates/unresolved ALT entries, account indices, original data, and metadata. Default parsing omits infrastructure programs; explicit RawInstruction subscriptions return all outer instructions.

The shared Pump CPI decoder accepts current Anchor event prefixes. Legacy ShredStream callbacks also forward raw instructions and retain standalone trades without merging unrelated trades into creates. The legacy log parser preserves nested Pump legs and drops events rolled back by parent invocations.

Examples include real transactions captured on 2026-10-19. Historical multi-hop fixtures remain regression cases, not new mainnet captures.

## Compatibility

- Default third-party Shred callbacks change to RawInstruction; explicit wrapper adapters remain available.
- Trade-only filters do not include raw instructions.
- ShredStream gRPC carries pre-execution data, not Yellowstone execution metadata.
- Existing event/method names are retained; third-party internal buy/sell methods are not guessed.
- PumpfunEvent and DexInstruction add RawInstruction; exhaustive matches need a new arm.

## Validation

Raw payload/order and current signed transaction regressions passed. Library, compatibility callback, nested invocation, and rollback checks passed.
